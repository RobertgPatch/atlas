## Exact exception and release decision

This exception temporarily defers *manual evidence as a pre-deployment approval gate* for unique Tony/Robert human identities, production MFA, the existing K-1/Restricted-data inventory, WISP and incident/breach readiness, legal/applicability review, operator edge-cost acknowledgement, and production restore evidence. These risks remain open and must not be described as remediated, compliant, or CI-verified.

The only release-eligibility decision for a new AWS production release is:

1. The clean release source is the current commit on the canonical `RobertgPatch/atlas` `main` branch, not merely a feature branch based on `main`.
2. A `push` run of `.github/workflows/security-ci.yml` for that exact commit has completed successfully with both **Application security gates** and **Terraform security gates** successful. Pull-request results, stale commits, missing jobs, and skipped or failed jobs do not qualify.

Passing these criteria authorizes the existing operator-controlled AWS `Plan`, `Prepare`, and `Apply` workflow during this exception's effective window. It does not assert that the site is otherwise safe or that the deferred requirements have been completed. The operator does not need separate sign-off on the deferred evidence rows before initiating this release.

Rollback does not rewind production data or Terraform state. The operator records the incident and obtains qualified response help where needed.
